# Substitutions courantes (mot non approuvé → alternative STE)

Liste de travail, non exhaustive. Les technical names et technical verbs restent autorisés.

| Non approuvé | Utiliser |
|---|---|
| accomplish, perform, carry out, conduct | do |
| adjust (au sens vague) | set, change |
| allow, permit, enable (au sens « permettre ») | let |
| approximately (dans une procédure, si possible) | approximately / about |
| assist, facilitate | help |
| attempt | try |
| check (verbe) | examine, make sure |
| commence, initiate | start |
| comprise, consist of, include (au sens « être fait de ») | have, contain |
| demonstrate, indicate, display (au sens « montrer ») | show |
| determine, locate, identify (au sens « trouver ») | find |
| due to, owing to | because of |
| ensure, verify, confirm | make sure |
| eliminate | remove |
| figure out | find |
| in order to | to |
| inform, notify | tell |
| maintain (au sens « garder ») | keep |
| modify | change |
| need, require (verbe) | be necessary (*It is necessary to…*) |
| obtain, acquire, retrieve | get |
| prior to | before |
| provide, furnish | give, supply |
| regarding, concerning | about |
| subsequent to, following | after |
| terminate, cease, halt | stop |
| utilize, employ | use |
| via | through |
| whether | if |
| would, could (conditionnel) | will, can (ou reformuler) |
| it is recommended that | (impératif direct) |
| please note that | (supprimer, ou une NOTE) |

## Exemples de réécriture

| Avant | Après (STE) |
|---|---|
| Please ensure that the server has been restarted prior to running the migration. | Restart the server. Then do the migration. |
| The configuration file should be modified in order to enable logging. | Change the configuration file to start logging. |
| Database connection pool size limit parameter | The size limit parameter of the database connection pool |
| If you would like to deploy, you need to run the CI pipeline first. | Before you deploy, run the CI pipeline. |
